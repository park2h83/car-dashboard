# 🚗 자동차 계기판

아이패드 Safari 에서 가지고 노는 아이용 자동차 계기판입니다.
빌드 도구·외부 라이브러리 없이 HTML/CSS/JS 만으로 만들었고, 소리는 Web Audio 로 합성합니다.

- 엑셀·브레이크·시동·기어·깜빡이·비상등·전조등·와이퍼·공조 등 조작
- 속도·RPM 바늘, 경고등, 제한속도·과속 경고, 내비, 자율주행 AI, 길 위 이벤트, 밤·비
- 여러 가지 계기판 테마, 장난감 운전면허증 만들기, 운전 시간 제한(부모님 설정)

## 아이패드에서 쓰기
1. Safari 로 이 사이트 주소를 엽니다.
2. 공유 버튼(□↑) → **홈 화면에 추가**. 홈 화면 아이콘으로 열면 전체 화면이 되고, 한 번 연 뒤에는 인터넷 없이도 열립니다.
3. 처음 열 때 운전할 친구의 이름과 어린이집 이름(선택)을 입력합니다.
   이름·면허증 사진·놀이 시간은 **그 아이패드 안에만** 저장되고 어디로도 보내지 않습니다.

PC 에서는 키보드로도 조작할 수 있어요: ↑ 엑셀, ↓ 브레이크, 브레이크 + Enter 시동, P/R/N/D 기어, Q/E 깜빡이, H 비상등, A 자율주행.
